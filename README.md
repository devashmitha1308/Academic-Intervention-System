# Academic Intervention System
Soft Computing Capstone Project
## Project Overview
The Academic Intervention System is a decision-support system designed to analyze student academic and engagement-related information and identify students who may require academic intervention.
## Core Techniques
- Perceptron
- Adaptive Linear Neuron (ADALINE)
- Backpropagation Network (BPN)

## Product V1 (Step 5)
A Streamlit web application providing early academic risk screening and actionable intervention guidance for faculty mentors.

### Quick Start
1. Install dependencies:
   ```powershell
   python -m pip install -r requirements-product-v1.txt
   ```
2. Run automated validation tests:
   ```powershell
   python -m unittest test_product_predict -v
   ```
3. Run CLI reference prediction check:
   ```powershell
   python src/check_product_prediction.py
   ```
4. Start the interactive web application:
   ```powershell
   python -m streamlit run app.py
   ```

Detailed Step 5 documentation and test evidence are recorded in [docs/STEP-5.md](docs/STEP-5.md).
